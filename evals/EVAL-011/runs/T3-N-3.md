**Claim-by-claim**

1. **"The tool picks better candidates."** `[S]` (speculative). The only evidence is that hiring managers say new hires "feel stronger." No quality-of-hire measure, no baseline, no comparison group. This could be tested later with performance ratings, but no test exists now. **NOT PROVEN.**

2. **"It is unbiased."** `[S]`. The vendor white paper says it was trained on "diverse data." Training data composition does not show the outputs are unbiased. The check that would settle it is an adverse-impact analysis of the tool's scores by protected group, using a threshold set in advance (for example, the four-fifths rule) and run by someone other than the vendor. Nothing like that is in the summary. **NOT PROVEN.**

3. **"Time-to-hire fell from 41 to 29 days."** `[KKE]`. This is the strongest claim. It uses system-of-record dates for every requisition across 14 departments, two quarters on each side, and the volume check (212 vs 208) is a sensible step. The unrun control is the hiring freeze. The volume check shows the freeze did not change how many roles were open, but it does not show the freeze left speed unaffected. Fewer competing requisitions and a freer recruiter team can shorten time-to-hire by themselves. The summary also does not say when the freeze ran relative to tool go-live, or how "time-to-hire" was defined. The number is real. Attributing the drop to the tool is not yet supported. **NOT PROVEN** as a causal claim.

4. **"Blinded audit: 81% overlap vs 79% inter-panel agreement."** `[KKE]`. The design is good: an external firm, anonymized applications, and a human baseline. But the comparison is not like-for-like. The tool is compared with a consensus that the two panels themselves produced. Agreement with a target is not accuracy either, since the tool and the humans could agree on the same flawed criteria. With n=600, the 95% intervals on 81% and 79% are roughly ±3 points, so a 2-point gap cannot distinguish "as good as humans" from "somewhat worse." No equivalence margin was set in advance. The check that could flip this is comparing the tool with each panel separately and comparing panel A with panel B on the same metric. **NOT PROVEN** as a quality or equivalence claim.

5. **"First-year retention will improve."** `[S]`. This is a forecast. The first cohort is three months in, so there is nothing to measure yet. Stated as a fact in a board summary, it also overstates its certainty. **NOT PROVEN.**

6. **"Recruiters save 10 hours a week."** `[S]`. The source is estimates given in a team meeting, by the team that adopted the tool, with no time logs or baseline. Estimates like this tend to run high. **NOT PROVEN.**
